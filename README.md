# Titanic Survival Prediction

## Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning. Multiple classification algorithms were trained and compared to identify the best-performing model.

## Features
- Data preprocessing
- Handling missing values
- Exploratory Data Analysis (EDA)
- Model training and evaluation
- Hyperparameter tuning using GridSearchCV
- Feature importance analysis
- Gradio interface for prediction

## Machine Learning Models
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest (Best Model)
- Support Vector Machine (SVM)
- Artificial Neural Network (ANN)

## Best Model
Random Forest Classifier

**Accuracy:** 83%

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Gradio

## Dataset
Titanic Dataset from Kaggle

## How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Open the notebook

```
Titanic_Survival_Prediction.ipynb
```

3. Run all cells.
